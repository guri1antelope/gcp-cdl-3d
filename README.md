# GCP CDL 3D合格クエスト（目標：2026年12月15日合格）

Google Cloud Digital Leader (CDL) 試験対策用、3Dスマホ最適化Webアプリです。
丸暗記ではなく「企業のビジネス課題・経営要件からどのGCPサービス・判断軸を選ぶか」をゲーム感覚で反復マスターできます。

## 🎯 主な機能
- **収録問題**: CDL模擬問題 全200問（全6セクション）
- **ビジネス即答あんちょこ**: 全問に「このビジネス課題・キーワードならこれ！」という要点まとめを付属
- **学習モード**:
  - セクション別ステージ学習（全20ステージ・1回10問）
  - 課題フラッシュ（ビジネス要件を瞬時に仕分けする高速特訓）
  - 弱点リベンジ（間違えた問題・要復習チェックの集中再出題）
  - 本番模擬試験（50問・90分タイマー実力測定＆セクション別正答率）
- **相棒3Dボクセル育成**:
  - Three.js による3Dボクセル相棒（柴犬など）
  - タッチでジャンプ、ドラッグで360度回転、ごはん（リンゴ・肉）でEXP獲得＆進化
  - 職階称号システム（見習いDX推進担当 ➔ クラウド戦略マネージャー ➔ CDLマスター）
- **試験日カウントダウン**:
  - 2026年12月15日までの残日数を常時表示
- **端末間データ引き継ぎ**:
  - スマホとPC間でセーブデータを同期できる引き継ぎコード機能

## 🚀 使い方

### 1. Webで直接遊ぶ（PC不要）
GitHub Pages にデプロイ済みのため、以下のURLからスマホやPCのブラウザでそのまま利用できます：
`https://guri1antelope.github.io/gcp-cdl-3d/`

### 2. ローカル環境で遊ぶ場合（Windows）
`スマホで遊ぶ_サーバー起動.bat` をダブルクリックして起動し、表示されるURL（`http://localhost:8080/` またはローカルIP）を開いてください。
